# Registrar un hábito

**Categoría:** Vida diaria. **Entrega:** guía de montaje manual.

Añade fecha y hábito a una nota que mantienes tú.

## Crear en Atajos

Abre Atajos → + → Nuevo atajo y ponle este nombre. Añade las acciones en este
orden. Los nombres pueden variar con el idioma y la versión; se incluye el nombre
en inglés para buscarlas. Selecciona las variables mágicas, no escribas sus nombres
como texto.

1. **Elegir del menú / Choose from Menu.** Opciones: Paseo, Lectura, Ejercicio y Otro.

2. **Texto / Text.** En cada rama asigna el nombre del hábito; en Otro solicita texto.

3. **Fecha actual / Current Date.** Formato yyyy-MM-dd HH:mm.

4. **Buscar notas / Find Notes.** Busca exactamente la nota «Registro de hábitos» en una carpeta elegida.

5. **Si / If.** Si no existe, crea esa nota; si existe más de una, elige una manualmente.

6. **Añadir a nota / Append to Note.** Añade «[fecha] · [hábito]» a la nota elegida.

## Prueba en tu iPhone

Ejecuta con contenido de prueba. Revisa cada pantalla y el resultado antes de
usarlo con datos reales. Si solicita permisos, comprueba que corresponden a las
acciones descritas. Cancela si aparece una app o una acción distinta.

## Límites y efectos

Requiere Notas. Cada ejecución añade una entrada, incluso si repites el mismo hábito. No evalúa salud ni sustituye asesoramiento profesional.
