# Leer texto en voz alta

**Categoría:** Accesibilidad. **Entrega:** guía de montaje manual. Incluye borrador nativo sin firmar.

Introduce texto y escúchalo con una voz del dispositivo.

## Crear en Atajos

Abre Atajos → + → Nuevo atajo y ponle este nombre. Añade las acciones en este
orden. Los nombres pueden variar con el idioma y la versión; se incluye el nombre
en inglés para buscarlas. Selecciona las variables mágicas, no escribas sus nombres
como texto.

1. **Solicitar entrada / Ask for Input.** Tipo Texto; pregunta «¿Qué quieres escuchar?».

2. **Leer texto / Speak Text.** Usa la entrada solicitada. Idioma español; espera a que termine la lectura.

## Prueba en tu iPhone

Ejecuta con contenido de prueba. Revisa cada pantalla y el resultado antes de
usarlo con datos reales. Si solicita permisos, comprueba que corresponden a las
acciones descritas. Cancela si aparece una app o una acción distinta.

## Límites y efectos

Comprueba que la voz española esté descargada en Ajustes. El procesamiento y la disponibilidad de voces dependen del sistema. No envía mensajes ni guarda el texto.
