# Unir documentos PDF

**Categoría:** Documentos. **Entrega:** guía de montaje manual.

Combina archivos PDF en un documento nuevo.

## Crear en Atajos

Abre Atajos → + → Nuevo atajo y ponle este nombre. Añade las acciones en este
orden. Los nombres pueden variar con el idioma y la versión; se incluye el nombre
en inglés para buscarlas. Selecciona las variables mágicas, no escribas sus nombres
como texto.

1. **Seleccionar archivo / Select File.** Activa selección múltiple y elige solo PDF.

2. **Crear PDF / Make PDF.** Entrada: archivos elegidos; si tu versión ofrece Unir PDF, usa esa acción.

3. **Vista rápida / Quick Look.** Comprueba número y orden de páginas.

4. **Guardar archivo / Save File.** Pregunta dónde guardar; no reutilices el nombre de un original.

## Prueba en tu iPhone

Ejecuta con contenido de prueba. Revisa cada pantalla y el resultado antes de
usarlo con datos reales. Si solicita permisos, comprueba que corresponden a las
acciones descritas. Cancela si aparece una app o una acción distinta.

## Límites y efectos

Los PDF con contraseña, formularios o firmas pueden no conservar todas sus propiedades. Verifica el resultado antes de usarlo como documento oficial.
