# Extraer texto de una imagen

**Categoría:** Imágenes. **Entrega:** guía de montaje manual.

Usa OCR para copiar texto impreso desde una foto.

## Crear en Atajos

Abre Atajos → + → Nuevo atajo y ponle este nombre. Añade las acciones en este
orden. Los nombres pueden variar con el idioma y la versión; se incluye el nombre
en inglés para buscarlas. Selecciona las variables mágicas, no escribas sus nombres
como texto.

1. **Seleccionar fotos / Select Photos.** Selecciona una sola imagen.

2. **Extraer texto de imagen / Extract Text from Image.** Usa la foto anterior.

3. **Mostrar resultado / Show Result.** Revisa el OCR antes de copiarlo.

4. **Copiar en el portapapeles / Copy to Clipboard.** Copia solo después de revisar el resultado; elimina esta acción si no quieres reemplazar el portapapeles.

## Prueba en tu iPhone

Ejecuta con contenido de prueba. Revisa cada pantalla y el resultado antes de
usarlo con datos reales. Si solicita permisos, comprueba que corresponden a las
acciones descritas. Cancela si aparece una app o una acción distinta.

## Límites y efectos

OCR requiere una versión compatible de iOS y puede cometer errores, sobre todo con importes, nombres y números. La última acción reemplaza el portapapeles.
