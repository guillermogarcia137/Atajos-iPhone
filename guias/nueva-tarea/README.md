# Añadir una tarea con fecha

**Categoría:** Productividad. **Entrega:** guía de montaje manual.

Crea un recordatorio después de introducir su título y vencimiento.

## Crear en Atajos

Abre Atajos → + → Nuevo atajo y ponle este nombre. Añade las acciones en este
orden. Los nombres pueden variar con el idioma y la versión; se incluye el nombre
en inglés para buscarlas. Selecciona las variables mágicas, no escribas sus nombres
como texto.

1. **Solicitar entrada / Ask for Input.** Texto: ¿Qué necesitas recordar?

2. **Solicitar entrada / Ask for Input.** Tipo Fecha y hora para el vencimiento.

3. **Añadir nuevo recordatorio / Add New Reminder.** Título de la primera respuesta, vencimiento de la segunda y una lista que tú elijas. Activa Mostrar al ejecutar si está disponible.

## Prueba en tu iPhone

Ejecuta con contenido de prueba. Revisa cada pantalla y el resultado antes de
usarlo con datos reales. Si solicita permisos, comprueba que corresponden a las
acciones descritas. Cancela si aparece una app o una acción distinta.

## Límites y efectos

Necesita acceso a Recordatorios. Ejecutar el último paso crea un registro real. Prueba en una lista llamada Pruebas y comprueba la zona horaria.
