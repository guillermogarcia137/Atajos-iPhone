# Codificar texto en Base64

**Categoría:** Texto. **Entrega:** guía de montaje manual. Incluye borrador nativo sin firmar.

Representa un texto como Base64 para intercambiarlo entre herramientas.

## Crear en Atajos

Abre Atajos → + → Nuevo atajo y ponle este nombre. Añade las acciones en este
orden. Los nombres pueden variar con el idioma y la versión; se incluye el nombre
en inglés para buscarlas. Selecciona las variables mágicas, no escribas sus nombres
como texto.

1. **Solicitar entrada / Ask for Input.** Texto que quieres codificar.

2. **Codificar en Base64 / Base64 Encode.** Modo Codificar, sin saltos de línea. Entrada: el texto solicitado.

3. **Mostrar resultado / Show Result.** Resultado Base64. Copia solo si lo necesitas.

## Prueba en tu iPhone

Ejecuta con contenido de prueba. Revisa cada pantalla y el resultado antes de
usarlo con datos reales. Si solicita permisos, comprueba que corresponden a las
acciones descritas. Cancela si aparece una app o una acción distinta.

## Límites y efectos

Base64 no cifra ni protege secretos. El resultado puede revelar todo el texto original.
