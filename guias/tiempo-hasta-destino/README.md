# Consultar tiempo hasta un destino

**Categoría:** Movilidad. **Entrega:** guía de montaje manual.

Calcula una estimación de viaje desde tu posición.

## Crear en Atajos

Abre Atajos → + → Nuevo atajo y ponle este nombre. Añade las acciones en este
orden. Los nombres pueden variar con el idioma y la versión; se incluye el nombre
en inglés para buscarlas. Selecciona las variables mágicas, no escribas sus nombres
como texto.

1. **Solicitar entrada / Ask for Input.** Pide una dirección; no guardes una dirección real en el atajo que publiques.

2. **Obtener tiempo de viaje / Get Travel Time.** Origen: ubicación actual. Destino: dirección solicitada. Elige coche, a pie u otro modo compatible.

3. **Mostrar resultado / Show Result.** Muestra la estimación; no envíes mensajes automáticamente.

## Prueba en tu iPhone

Ejecuta con contenido de prueba. Revisa cada pantalla y el resultado antes de
usarlo con datos reales. Si solicita permisos, comprueba que corresponden a las
acciones descritas. Cancela si aparece una app o una acción distinta.

## Límites y efectos

Necesita ubicación y normalmente red/Mapas. La estimación puede no reflejar tráfico, accesibilidad o cambios recientes.
