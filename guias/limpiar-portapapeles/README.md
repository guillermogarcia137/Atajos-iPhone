# Vaciar el portapapeles

**Categoría:** Privacidad. **Entrega:** guía de montaje manual.

Reemplaza el portapapeles por una cadena vacía tras avisar.

## Crear en Atajos

Abre Atajos → + → Nuevo atajo y ponle este nombre. Añade las acciones en este
orden. Los nombres pueden variar con el idioma y la versión; se incluye el nombre
en inglés para buscarlas. Selecciona las variables mágicas, no escribas sus nombres
como texto.

1. **Mostrar aviso / Show Alert.** Texto: «Se reemplazará el portapapeles». Mantén el botón Cancelar.

2. **Texto / Text.** Deja el contenido vacío.

3. **Copiar en el portapapeles / Copy to Clipboard.** Usa el texto vacío. Activa Solo local si aparece.

## Prueba en tu iPhone

Ejecuta con contenido de prueba. Revisa cada pantalla y el resultado antes de
usarlo con datos reales. Si solicita permisos, comprueba que corresponden a las
acciones descritas. Cancela si aparece una app o una acción distinta.

## Límites y efectos

No borra historiales de gestores de portapapeles ni copias ya sincronizadas en otros dispositivos. Pruébalo con un texto sin importancia antes de confiar en su comportamiento en tu versión de iOS.
