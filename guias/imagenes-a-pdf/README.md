# Convertir imágenes a PDF

**Categoría:** Documentos. **Entrega:** guía de montaje manual.

Reúne imágenes seleccionadas en un PDF nuevo.

## Crear en Atajos

Abre Atajos → + → Nuevo atajo y ponle este nombre. Añade las acciones en este
orden. Los nombres pueden variar con el idioma y la versión; se incluye el nombre
en inglés para buscarlas. Selecciona las variables mágicas, no escribas sus nombres
como texto.

1. **Seleccionar fotos / Select Photos.** Activa Seleccionar varias. Elige las imágenes en el orden deseado.

2. **Crear PDF / Make PDF.** Entrada: fotos seleccionadas. Revisa el orden de páginas.

3. **Vista rápida / Quick Look.** Comprueba el documento antes de guardarlo.

4. **Guardar archivo / Save File.** Activa Preguntar dónde guardar y elige un nombre nuevo.

## Prueba en tu iPhone

Ejecuta con contenido de prueba. Revisa cada pantalla y el resultado antes de
usarlo con datos reales. Si solicita permisos, comprueba que corresponden a las
acciones descritas. Cancela si aparece una app o una acción distinta.

## Límites y efectos

El PDF puede contener información de las imágenes. Revisa las páginas y los metadatos antes de compartirlo. No borres las fotos originales.
