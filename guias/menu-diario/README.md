# Menú de accesos para el día

**Categoría:** Productividad. **Entrega:** guía de montaje manual.

Reúne tus atajos favoritos en un menú con nombres claros.

## Crear en Atajos

Abre Atajos → + → Nuevo atajo y ponle este nombre. Añade las acciones en este
orden. Los nombres pueden variar con el idioma y la versión; se incluye el nombre
en inglés para buscarlas. Selecciona las variables mágicas, no escribas sus nombres
como texto.

1. **Elegir del menú / Choose from Menu.** Crea Agenda, Nueva tarea, Hábito y Leer texto.

2. **Ejecutar atajo / Run Shortcut.** En cada rama selecciona el atajo correspondiente de esta colección, previamente creado.

3. **Añadir a pantalla de inicio.** Desde los detalles del atajo, elige un nombre corto y un icono. Opcional: asígnalo al botón Acción si tu iPhone lo admite.

## Prueba en tu iPhone

Ejecuta con contenido de prueba. Revisa cada pantalla y el resultado antes de
usarlo con datos reales. Si solicita permisos, comprueba que corresponden a las
acciones descritas. Cancela si aparece una app o una acción distinta.

## Límites y efectos

No activa automatizaciones ni envía mensajes por sí mismo. El botón Acción solo existe en modelos compatibles; las acciones de cada rama conservan sus permisos y efectos.
