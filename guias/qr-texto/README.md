# Crear un QR con texto

**Categoría:** Compartir. **Entrega:** guía de montaje manual.

Genera un QR de una nota o URL que tú introduzcas.

## Crear en Atajos

Abre Atajos → + → Nuevo atajo y ponle este nombre. Añade las acciones en este
orden. Los nombres pueden variar con el idioma y la versión; se incluye el nombre
en inglés para buscarlas. Selecciona las variables mágicas, no escribas sus nombres
como texto.

1. **Solicitar entrada / Ask for Input.** Tipo Texto. Pide el contenido del QR.

2. **Generar código QR / Generate QR Code.** Entrada: texto solicitado.

3. **Vista rápida / Quick Look.** Comprueba el QR con otro dispositivo.

4. **Guardar archivo / Save File.** Opcional: pregunta dónde guardar la imagen.

## Prueba en tu iPhone

Ejecuta con contenido de prueba. Revisa cada pantalla y el resultado antes de
usarlo con datos reales. Si solicita permisos, comprueba que corresponden a las
acciones descritas. Cancela si aparece una app o una acción distinta.

## Límites y efectos

Cualquiera que vea el QR podrá leer su contenido. No lo uses para exponer contraseñas, tokens o datos personales sin entender esa consecuencia.
