# Recordatorio de salida

**Categoría:** Vida diaria. **Entrega:** guía de montaje manual. Incluye borrador nativo sin firmar.

Muestra una lista breve antes de salir de casa.

## Crear en Atajos

Abre Atajos → + → Nuevo atajo y ponle este nombre. Añade las acciones en este
orden. Los nombres pueden variar con el idioma y la versión; se incluye el nombre
en inglés para buscarlas. Selecciona las variables mágicas, no escribas sus nombres
como texto.

1. **Texto / Text.** Escribe: Llaves, cartera, móvil, agua, auriculares y lo necesario para hoy; una línea por elemento.

2. **Mostrar resultado / Show Result.** Muestra el texto anterior.

## Prueba en tu iPhone

Ejecuta con contenido de prueba. Revisa cada pantalla y el resultado antes de
usarlo con datos reales. Si solicita permisos, comprueba que corresponden a las
acciones descritas. Cancela si aparece una app o una acción distinta.

## Límites y efectos

Es una lista visual de consulta; las marcas no se guardan y no se crean recordatorios. Personaliza los elementos para tu rutina.
