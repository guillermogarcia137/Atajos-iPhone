# Crear copias de fotos reducidas

**Categoría:** Imágenes. **Entrega:** guía de montaje manual.

Prepara imágenes más pequeñas sin sustituir las originales.

## Crear en Atajos

Abre Atajos → + → Nuevo atajo y ponle este nombre. Añade las acciones en este
orden. Los nombres pueden variar con el idioma y la versión; se incluye el nombre
en inglés para buscarlas. Selecciona las variables mágicas, no escribas sus nombres
como texto.

1. **Seleccionar fotos / Select Photos.** Activa selección múltiple.

2. **Cambiar tamaño de imagen / Resize Image.** Ancho 1600, alto automático.

3. **Convertir imagen / Convert Image.** Formato JPEG; calidad aproximada 85 %. Revisa la opción de metadatos si aparece.

4. **Guardar archivo / Save File.** Pregunta dónde guardar las copias. Selecciona una carpeta de exportación.

## Prueba en tu iPhone

Ejecuta con contenido de prueba. Revisa cada pantalla y el resultado antes de
usarlo con datos reales. Si solicita permisos, comprueba que corresponden a las
acciones descritas. Cancela si aparece una app o una acción distinta.

## Límites y efectos

JPEG pierde transparencia y no conserva animación. La conservación de metadatos depende de las opciones de Conversión; no presupongas que se han eliminado.
