# Guardar dónde has aparcado

**Categoría:** Ubicación. **Entrega:** guía de montaje manual.

Guarda una nota con la posición actual y la fecha.

## Crear en Atajos

Abre Atajos → + → Nuevo atajo y ponle este nombre. Añade las acciones en este
orden. Los nombres pueden variar con el idioma y la versión; se incluye el nombre
en inglés para buscarlas. Selecciona las variables mágicas, no escribas sus nombres
como texto.

1. **Obtener ubicación actual / Get Current Location.** Concede acceso solo si quieres guardar esa posición.

2. **Obtener detalles de ubicaciones / Get Details of Locations.** Extrae latitud y longitud.

3. **Fecha actual / Current Date.** Da formato a fecha y hora locales.

4. **Texto / Text.** Crea «Aparcamiento · [fecha]» y https://maps.apple.com/?ll=[latitud],[longitud] usando coordenadas con punto decimal.

5. **Crear nota / Create Note.** Guarda en una carpeta personal de Notas y revisa el resultado.

## Prueba en tu iPhone

Ejecuta con contenido de prueba. Revisa cada pantalla y el resultado antes de
usarlo con datos reales. Si solicita permisos, comprueba que corresponden a las
acciones descritas. Cancela si aparece una app o una acción distinta.

## Límites y efectos

La nota contiene ubicación precisa y puede sincronizarse con iCloud. El GPS puede ser impreciso en garajes. No envía la ubicación a ningún contacto.
